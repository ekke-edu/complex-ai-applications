# 1. API Basics

This project features a FastAPI-based API that generates text via a `POST /generate` endpoint using Google Gemini models.

## Getting Started

1. Create a `.env` file.
2. Add your key: `GEMINI_API_KEY=your_key`

## Running the API
```bash
make run
```
Access Swagger UI at `http://localhost:8000/docs`.
