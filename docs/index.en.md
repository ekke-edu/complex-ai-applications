# Complex AI Application Development

This project demonstrates a modern, State-of-the-Art microservice-based AI system built step-by-step through the following development phases.

📚 **Course Info:** [https://io.uni-eszterhazy.hu/downloadCourseInfo/101964](https://io.uni-eszterhazy.hu/downloadCourseInfo/101964)

---

## Semester Agenda (Branches)

The repository branches follow the gradual expansion of the software architecture:

- **`feature/01_fastapi-geminiapi`** – **Basics & API:** Async FastAPI backend.
- **`feature/02_rag-vector-database`** – **Vector RAG:** Document processing and semantic search in a local ChromaDB.
- **`feature/03_chat-memory-mongodb`** – **Stateful Memory:** Session-based chat history in a NoSQL MongoDB.
- **`feature/04_multimodal-vision`** – **Multimodal Vision:** Direct image analysis using the model.
- **`feature/05_graph-rag-neo4j`** – **Knowledge Graphs & GraphRAG:** Entity-relationship triple extraction stored in Neo4j.
- **`feature/06_mlops-docker-grafana`** – **Observability (MLOps):** Real-time performance tracking with Prometheus and Grafana.
